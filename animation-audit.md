# Tangra Animation Audit Report

A comprehensive, read-only audit of micro-interaction state changes, snaps, and instant teleportations across the Tangra codebase (`native/src/`).

---

## Executive Summary

Tangra features sophisticated custom animation infrastructure—including spring physics (`widgets.rs`), rolling odometer digits (`roll_text`), fluid fill shaders (`liquid_fill`), wave hover magnifiers (`wave_rows`), cursor morphing (`ui/cursor_morph.rs`), and bounding box transform glides (`canvas/glide.rs`).

However, this audit revealed **68 discrete micro-interaction snaps** where values, geometries, colors, or UI elements jump instantly in a single frame (`if condition { A } else { B }` or direct atomic mutation) rather than animating through these existing helpers.

The findings below are grouped by shared fix/helper, sorted by **Visibility** (High → Med → Low) and then by **Confidence** (High → Med). Low-confidence / borderline items are isolated in the final **Unsure** section.

---
